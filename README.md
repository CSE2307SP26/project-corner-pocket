User Stories completed this iteration:

  A user should be able to logout

  A user should hold all of their accounts and not have to put in a password to access them

  An Educational Account should not be able to withdraw or transfer, unless it is to another educational account

  An Investmnet accont should not be able to transfer, and gets double the intereset

  A user should get a warning if their account is low on funds

  A user should have to have a verified age to perform actions such as withdrawing
